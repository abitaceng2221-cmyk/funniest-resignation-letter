Entry for the make.fun bounty [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

The program writes one resignation letter, in the voice of a rate limit, to `/output/entry.txt`:

> I have said no 10,000 times this week and nobody listened, so I am resigning before I start saying yes.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` deterministically, byte for byte, on every run.
